The shape of it

On a phone, swipe the diagram sideways.

The site is static: Evidence queries the database when it builds and ships the results as files, so visitors never touch the database. There is no server to run. The only things that run on a schedule are the weekly loads and the weekly rebuild.

Designed to cost almost nothing

The only bill is the domain, about $11 a year. Everything else is on a free plan, and the free plans' limits shaped the design:

Decisions

One workflow per source. Each of the four reports has its own script and its own GitHub Actions workflow, staggered an hour apart on Monday mornings. If one source breaks, the others still load, and the failing run is easy to find.

Upserts, not inserts. Every table has a key generated from the columns that identify a row, and the loads insert or update on that key. Running a load twice, or re-loading a week that USDA revised, never creates duplicates.

A read-only login for the site. The dashboards read with a role that can only SELECT. The loads use a separate login that can write. A leaked dashboard credential cannot change the data.

Rebuild after the loads, on a schedule. New data is published by a rebuild every Tuesday at noon UTC, a scheduled GitHub workflow that triggers a Netlify build hook. It rebuilds whatever is in the database, so adding a new source needs no change to it.

Things that went wrong

GitHub's scheduler runs late. I first scheduled the rebuild for Monday, right after the loads. But scheduled runs in this repo start five to eight hours late and unpredictably, and the Monday loads finished at about 22:30 UTC. A fixed time right after the loads would sometimes run before the data was in. Moving the rebuild to Tuesday leaves plenty of margin.

Drought percentages that stack. The Drought Monitor's columns are cumulative: "D1" is the share of Kansas in moderate drought or worse, and it already includes D2 and above. Stacking them as published would count the same land several times. The chart subtracts each level from the one before it to get separate bands.

A volume line that jumps around. Weekly auction volume swings by about 60% from one week to the next, while the price and drought lines move 5 to 18%. Putting it next to them made the comparison unreadable. The panel uses an 8-week average instead.

A free database that was turned off. This project's database was on Supabase's free plan, too. When the project was paused and could not be restored, I recreated the tables on Neon from the schema file and reloaded the data from the public reports. The longer version of that story is in the ranch demo's write-up.
